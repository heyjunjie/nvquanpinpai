# 第二阶段验收记录

## 方案落实

完整批准方案与验收标准原文保存在 [PHASE2.md](PHASE2.md)。首页采用批准的标题、副文案和宣言，搜索与主按钮前置；投稿作为次要操作。近期收录事件使用已有截图、事件经过、发布主体、事实核实状态、品牌回应与关键缺口，卡片一次点击直接打开事件。按收录时间排列，不将旧事件称为近期发生或制造热度。

页面顺序为立场与搜索、近期收录事件、品牌目录、回应与更正、消费者观点。统计位于下方，人数直接显示，图表与排行按需展开。四维筛选保持组合查询，手机折叠时保留条件和选择数量。黑白正文与少量深红按钮替代原配色，核实状态采用明确文字和中性标记。

详情页的关键主体关系与材料缺口仍在图片前明确展示，首张图先于具体经过，完整核实表格位于附件后。原视频未取得的既有说明在对应卡片和详情开头明确保留；未从没有此说明的条目推断视频缺失。店铺账号不代表总部，未知主体继续待核。图片在当前页按窗口比例预览，保留缩放、适合窗口、按宽适配、原尺寸、下载和关闭。

## 本地验证

- `npm run typecheck`、`npm test`、`npm run build`通过。测试覆盖注册、署名投稿、审核、私人附件权限、图像与视频投稿、视频分段请求、贡献署名与排行、访客永久累计去重、结构化摘要、日期冲突、关联纠错和公开变更记录。新增显示层测试确保仅引用已有主体信息，不提高核实等级，观点与未审核记录不混入事件，排序不使用猜测事件日期。
- 浏览器检查1440、390、320像素宽度；文档宽度不超窗口，手机筛选默认折叠。三个选项与剪吊牌关键词组合返回3品牌/3记录；折叠再展开仍保留选择。`logitech`返回1品牌/2记录；无匹配词返回0/0，可清空恢复。
- 卡片直达事件；事件、品牌及附件保留独立链接。刷新、品牌进入事件后关闭返回品牌、浏览器前进后退、预览关闭均实测。浏览器无前端错误。消费者观点及老黄署名保留，不覆盖苹果品牌摘要。统计图仍为竖向柱形，手机采用清楚的数字和文字。

## 发布与数据保护

使用已有HK VPS、notbuy.top和公开GitHub仓库；不调整其他主站域名、Caddy、账户角色、密码或数据目录。发布脚本构建精确提交镜像，执行后端、档案及显示层测试，停机备份后只替换本服务，保留旧容器；隔离恢复检查使用数据副本。

线上精确版本以 `/api/version`、镜像revision和VPS的 `active-release.txt`核对，代码对应同一Git提交。部署后的网络验收、数据与文件指纹、恢复演练以及三种宽度的线上截图另存工作区 `outputs/第二阶段_部署验收报告.md`，不把本地检查当作线上验收。
