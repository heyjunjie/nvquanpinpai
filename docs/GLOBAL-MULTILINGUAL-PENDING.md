# 全球站点与多语言模式：首期与后续

首期为中文与英文：全球目录、分类、事件阅读及署名投稿已实施，并通过隔离环境验收。2026-10-13，站长再次明确：项目应做成全球站点，并提供多语言模式。海外研究包与正式双语站点分别交付；后续范围是第三种语言、历史档案译文和持续补证。

## 已确认的方向

- notbuy.top 面向全球消费者，海外资料进入正式站点的品牌与事件体系。
- 站点提供语言切换，多语言范围包括导航、搜索、筛选、事件阅读和署名投稿流程。
- 继续使用既有浅色严肃报刊风格和手机适配。
- 全球内容保留事件投放地区、实际发布主体、原始语言、来源、时间精度、品牌回应及待核事项。
- 既有资料、媒体、账户、永久访客历史和两个主站须继续保留。

## 当前实际状态

- 首期发布29条海外记录与双语入口；随后将原本分开的中英文界面合并成一套 React 应用。默认 `/` 是简体中文，`/en` 是英文，`/global` 仅保留兼容入口。目录、统计、阅读器、筛选及投稿均共用组件，切换语言保留页面与草稿。当前验收见 UNIFIED-GLOBAL-20261013.md，首期记录见 GLOBAL-SITE-20261013.md。
- 海外与历史研究包在 outputs/global-brand-research-20261013，本批将29条核查后的海外记录与55项任务并入正式档案；未取得的原片原文保留补证任务。
- README已调整为全球档案定位，并标明首期中文、英文及旧档案未翻译限制。

## 首期实施与后续范围

1. 全球目录与地区分类，避免将全球品牌总部、当地运营商、授权店铺混作同一主体。
2. 可扩展语言字典、独立语言入口和保留当前事件的语言切换；原中文链接继续有效。
3. 已核验的事件标题与摘要译文；原图、原文和来源保留，标明译文性质与未翻译内容。
4. 多语言页面标题、描述、语言声明、对应语言链接与站点地图。
5. 多语言投稿、审核与纠错的数据关联，以及桌面和手机实际流程验收。
6. 按现有独立部署流程同步源码与发布，核对现有数据、账号、媒体和主站不变。

依据站长本次“全球站点开始干”的授权，首期按现有方案实施中文与英文。第三种语言及旧中文档案的全量翻译尚未完成，后续按受众与可核对材料逐步扩展。
