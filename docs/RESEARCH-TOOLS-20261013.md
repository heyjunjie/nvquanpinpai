# 买前速查与引用工具

这批功能把现有公开档案变成便于查阅、核对和引用的资料工具，不新增品牌指控或研究结论。

- `/lookup`：按中文名、英文别名、大小写、全半角和多词组合匹配品牌；首页搜索也共享同一份别名表。展示事件数、附件数、日期待核数、最近事件和回应。无记录时明确说明资料缺口，不给品牌作安全认证。查询参数可分享，查询页 noindex，入口加入 sitemap。统计仅记录 `/lookup` 页面，不存搜索词。
- `/cite/:id`：复制带档案链接的引用文案，下载 Markdown 或 JSON。包括事件与来源日期、收录时间、原文、导读、署名、附件来源/指纹、回应、待核事项和公开更正；不包含账户 ID、投稿者私有字段或未审核记录。文件为生成时快照，之后的撤回/更正须回到原档案核对。
- `/sources/:key`：以既有 SHA-256 查同字节的公开附件关联。只表示文件相同，不确认真实性、原始出处或独立证据数量。裁剪、重新编码及视觉相似图片不在这一阶段的识别范围内；没有宣称 OCR 或全网反向搜图。

## 数据与访问边界

服务端每次请求从当前已批准公开档案生成结果；源档案变为待审核或撤回时，引用页、引用下载、同图入口立即返回 404。相同文件若另有独立公开投稿，仅保留其公开关联。未审核附件不进入匹配数量。使用字段白名单生成 JSON，来源只允许 HTTP/HTTPS，页面和 Markdown 按各自格式转义。

`/api/citations/:id?format=markdown|json` 与 `/api/materials/:key` 为只读公开接口，无数据库迁移。下载响应为附件、no-store、nosniff。引用和指纹详情不进 sitemap；既有独立事件链接是引用的权威入口。第三方材料没有因代码 MIT 许可而被重新授权。

## 验证

`npm run typecheck` 与 `npm test`。新增测试覆盖别名、时间精度、公开范围、私有字段、来源协议、HTML/Markdown 转义、重复附件、撤回立即隐藏及实际 HTTP 下载接口。浏览器检查包括桌面、390px 与 320px 手机宽度，实际复制及 Markdown/JSON 下载、事件内入口、附件关联页。线上验收和数据保存审计另存部署记录。

## 后续范围

图片 OCR、相似图匹配、全网反向搜图、国际资料核验与新增发布不属于此批已完成功能。搜索引擎站长验证仍需要对应所有权验证值；页面可抓取不等于已经收录或带来新增流量。
