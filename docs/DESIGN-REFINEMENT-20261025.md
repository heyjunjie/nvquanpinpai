# 报刊档案版面精修

本轮依照站长的八项设计要求，深化既有浅色严肃报刊方向。品牌目录仍优先，统计保留在桌面页边与手机正文之后；中英文继续共用同一应用，资料、账号、审核、上传及永久访客统计没有迁移或改写。

## 版面与字体

新版采用有更强主次的报头、标题与索引行，保留纸色、深墨色、灰色细线和酒红色操作。中英文标题使用本地托管的 Newsreader 与 Noto Serif SC；字体文件按内容指纹命名，许可证和来源在 public/fonts。中文子集覆盖当前界面及已公开档案标题的已知字形，其他字形保留可读衬线回退。正文和操作继续使用系统中文无衬线字体。

首页的资料年份来自可定位年份的公开事件，未知日期不推断。它是档案范围提示，不是创站年份。手机窄于361像素时让目录搜索优先；年份仍可在事件时间线选择器和原记录中查阅。手机品牌目录改为单列，避免长英文名称与事件标题挤在一起。

资料阅读器、表单、统计图和独立档案页共享字阶、间距、焦点和控件规范。图片继续适窗预览和保留原比例。弹窗只在进入时做一次轻量纸页展开；减弱动态效果时禁用，全文和操作始终可读。

## 设计参照与判断边界

参照用于比较编排、字体与互动的完成度，不代表本站获得或达到任何奖项认证。Awwwards 对 Miranda Paper Portfolio 的报刊编排说明见[官方出版物](https://assets.awwwards.com/awards/gallery/2023/07/HOT-RIGHT-NOW-BOOK-2023.pdf)。Webby 的[杂志与出版类别](https://winners.webbyawards.com/winners/websites-and-mobile-sites/general-desktop-mobile-sites/magazine-or-publication)列出 i-D 与 The New Yorker 的2025奖项；两站的编辑层级和阅读路径作为功能型出版界面的参照。FWA 的[Hearst Exhibit 2026](https://thefwa.com/cases/elle-and-esquire-exhibit-2026)作为编排与互动研究入口，该页面的抓取没有提供可读的动效证据，不据此宣称已完成其动效的逐帧比较。

本项目保持 Read / Operate 场景，原始证据是内容图像。没有新增装饰性生成图片、假数据、假认证或屏幕接管动效。

## 验收

检查字体与字形加载、主次层级、分组与留白、颜色对比、弹窗和控件反馈、减弱动态效果、双语切换、窄屏图表及表单草稿保留。检查桌面1440/1280像素、手机390/320像素，并补充实际2560像素浏览器宽度。初版发现超宽屏英文按钮折行、320像素辅助信息过高，随后一批修正。

截图采用当前实际渲染；浏览器截图尺寸异常的弹窗另行重拍，不能把异常缩图当成版面证据。隔离环境含明确标注的测试投稿和统计，绝不随源码部署到生产。正式发布只更新代码与字体，保留数据库、媒体、访客密钥和两个原主站，先备份再切换。

独立设计审查提出两项修正：英文手机菜单必须完整保留，英文1280×720首屏需要显示首批品牌、品类及事件入口。一批调整后重拍同样尺寸，审查者将两项均评为 resolved，并给出 ship；该结论限定于修正清单，不是对所有页面再次完整审查，也不是奖项认证。最终截图保存在本地忽略目录 `.impeccable/review/`，不把测试内容随仓库发布。

本地 TypeScript 检查、14组测试和构建已通过；界面实测包括菜单展开、同页图片适窗、英文切换后的草稿与筛选保留、焦点和减弱动态效果。正式部署还会运行发布脚本的构建与测试、公开路由/字体/媒体检查及隔离备份恢复；这些运行结果以实际发布记录为准，本文不预先声明上线成功。
