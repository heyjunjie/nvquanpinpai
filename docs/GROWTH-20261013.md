# 搜索与社交增长执行单

目标：让查询具体品牌事件的人找到完整资料，再用可核对的事件专题获得分享与回访。以零广告预算开始；不承诺排名或虚构浏览量。

## 已做的站内基础

- 品牌、事件、附件采用真实路径；旧 `#/` 链接继续兼容，普通点击保持当页弹窗。
- 公开页面由服务器输出文字、来源与真实链接，不依赖 JavaScript 才能读取。未审核和已撤回内容不进入页面、站点地图或 RSS。
- 每页独立标题、描述、canonical、Open Graph 与 WebPage 结构化信息；不虚构评级、精确发生日或新闻作者。
- [全部档案](https://notbuy.top/archive)、[店铺争议](https://notbuy.top/topics/store-posts)、[历史回看](https://notbuy.top/topics/history)、[品牌回应](https://notbuy.top/topics/responses)。
- [站点地图](https://notbuy.top/sitemap.xml)、[robots.txt](https://notbuy.top/robots.txt)、[RSS](https://notbuy.top/feed.xml)。RSS 排序时间是本站收录/修订时间，条目单列事件日期。
- 事件“分享事件摘要”：手机打开系统分享；不支持时复制摘要与独立链接。
- 后台“流量来源”：近 30 天按渠道去重人数、访问人天、每日访客。沿用永久访客标识，不重置首页累计人数。新来源数据从本版开始，不能反推历史来源。

实现依据：[Google JavaScript SEO 基础](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics)、[可抓取链接](https://developers.google.com/search/docs/crawling-indexing/links-crawlable)、[URL 结构](https://developers.google.com/search/docs/crawling-indexing/url-structure)。公开可抓取不等于搜索平台已经收录。

## 搜索提交：需要站长账户完成的最后一步

1. 在 Google Search Console 添加 `notbuy.top` 域名资源，将其生成的专属 TXT 值加到现有 DNS；保留现有 NS、A 和其他站点记录。若已有资源，直接使用，不重复添加。
2. 所有权验证后提交 `https://notbuy.top/sitemap.xml`，再检查首页、一个事件页、一个专题页的 URL 检查结果。
3. Bing Webmaster Tools 与百度搜索资源平台分别使用其账户流程。不要把 `site:` 查询数量当正式收录报表。

当前未取得这些账户的所有权验证值，未声称已提交或已收录。拿到验证值后只需补这一项，无需重新建站。

## 两周节奏

| 时间 | 搜索与内容 | 社交动作 | 看什么 |
|---|---|---|---|
| 第 1 天 | 提交 sitemap，保存收录基线 | 发布一条站点介绍，主页挂固定链接 | 来源统计开始记录 |
| 第 2–3 天 | 完善店铺专题的原片与主体依据 | 发布“剪吊牌是谁发的”图文 | 进入店铺专题的人数 |
| 第 4–5 天 | 核对德芙回应原件与日期冲突 | 发布“文案与回应放一起看” | 事件访问、收藏、有效补证 |
| 第 6–7 天 | 查看搜索实际展示词，不按想象堆关键词 | 发布“原视频缺失意味着什么”短视频 | 完播率与站内来源人数 |
| 第 8–10 天 | 补最常被搜索事件的来源缺口 | 发布一条历史材料回看 | 旧文搜索展示是否增加 |
| 第 11–14 天 | 看专题/事件的收录与点击，再补关联链接 | 发布一次公开更正或新增原件说明 | 回访、投稿、审核通过贡献 |

频率是编辑排期，不是自动群发计划；优先选两个已有账号经营，避免复制同文铺满平台。未获外部账号发帖授权，本轮只生成可发布草稿。

## 带来源标记的分发链接

格式：`?utm_source=weibo&utm_medium=social&utm_campaign=store_posts_202610`。

来源支持 `weibo / xiaohongshu / douyin / bilibili / wechat / x / github`；搜索引荐识别 `google / bing / baidu`。后台当前按来源汇总，不把 campaign 宣称为已实现的细分报表。平台不允许站外链接时遵守其规则，用账户简介或允许的入口，不用变形链接绕过限制。

浏览器会在当前会话内保留最近渠道（30 分钟无活动后失效），避免站内跳转被重复归入直接访问；显式新渠道参数或新外部引荐可覆盖。

近 30 天去重人数不是每日人数之和；同一人可从多个渠道进入，渠道人数也不能相加。分享平台可能不传引荐信息，未带来源参数的访问会落到“直接 / 来源未知”。

## 素材模板与决策

每条用“具体问题 → 原图/原文 → 来源与日期 → 回应/待核 → 一个资料链接”。标题可以尖锐，事实必须可核对。不要把“未找到道歉”改写成“拒不道歉”，不要把店铺账号直接当总部。

首周只建立基线。第二周比较哪类内容带来更多真实查阅和有效补证；有稳定访问后再决定广告预算。搜索曝光/点击需要站长平台数据；社交播放、收藏需要对应平台后台，本站不伪造这些指标。
