# 全球站点首期实施

本批把已研究的海外案例发布为正式档案，并上线中文全球目录 `/global` 和英文入口 `/en`。现有中文地址保持有效，语言切换保留品牌、事件、附件或任务关联。首期仅中文、英文；没有译文的历史中文档案明确标注原文，不能把界面翻译当作全站内容已翻译。

海外案例逐条保留市场、来源语言、来源可访问情况、发生时间精度、实际发布主体、回应与判断边界。英国监管决定与媒体报道区别处理，澳大利亚仅有索引的决定作为待核线索。没有找到道歉，不推断为明确拒绝。没有原图／原视频，不伪造附件；需要的材料转为具体补证任务，署名投稿进入原审核流程。

实现顺序：核查来源和双语摘要；新增版本化案例目录及幂等导入；接入地区／事件主题／回应筛选和双语阅读投稿；补齐语言元数据与站点地图；测试隔离环境的投稿审核、图片和视频；实际桌面／手机检查；同步公开源码；带完整备份独立部署；对比所有历史数据库行、上传文件、密钥和主站容器。

发布只追加新档案与任务。重新启动不会重复添加，也不会恢复撤回档案或覆盖管理员修改。全球分类和译文采用独立元数据表，与原文和审核状态分别保存。新增编辑整理材料不计用户贡献排行。

隔离环境验收：类型检查、构建与12个测试套件通过；手机320/390像素与桌面1280像素检查无横向溢出；真实署名投稿提交PNG和H264视频，审核前附件不可公开读取，审核后保留投稿人和任务关联，图片适合窗口预览、缩放和关闭，视频实际播放完成。测试投稿不写入正式站点。

生产发布通过 deploy/release.sh 的同版本镜像测试与健康检查；VPS的 release-manifest.txt 记录版本、备份和原容器。发布前后另行对比所有旧数据库行、上传文件、密钥配置及主站容器，访问验收报告保存在本次交付工作目录。原片和原始回应等长期缺口继续开放任务，不以本批上线宣称已全部补齐。

原文摘要、回应、日期或核实分类经管理员修订后，旧英文摘要自动失效，英文页面回退到明确标注的当前中文原文，避免译文悄悄保留过期结论。
