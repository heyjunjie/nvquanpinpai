# 一个全球站点，随时切换语言

本次统一替代此前中文首页、中文全球目录和英文海外入口三套界面。默认首页 `/` 使用简体中文，`/en` 是同一站点的英文界面；`/global` 保留兼容入口，规范地址为首页。

两种语言共用 React 组件、生成的 JS/CSS、品牌与事件数据、统计、账户、投稿、图片预览和视频播放器。切换不重新挂载应用，不清除当前关键词、市场筛选、关注、已读或投稿草稿与待上传附件；品牌、事件、附件和补证任务标识保持不变。

市场与回应情况进入首页组合筛选。界面词典仅翻译明确的界面文案；表单保存的品牌、类别和关联 ID 保留原标识。有效海外英文摘要使用已整理译文；过期译文回退到当前原文。旧中文档案、作者说明和原始媒体保留原语言并标注，不宣称全量资料已有英文译文。

品牌、事件、附件、补证、完整档案、速查、专题及更新页面均使用同一应用。公开 HTML 保留可读资料、语言声明、对应语言链接与规范地址。引用和文件溯源工具继续提供原始资料快照。统计仍由服务器永久累计；语言切换不会建立另一份统计或贡献排行。

本次仅更新代码，无新的品牌事实、生产投稿或数据库内容导入。VPS 发布前备份，核对已有记录、上传文件、用户和受保护配置；主站容器与 Caddy 配置保持不变。隔离环境的测试投稿及媒体不会随源码发布。

验收覆盖类型检查、14 组测试、默认语言与往返路由、表单原值、原文/过期译文、权限边界，以及 1280 桌面和 390/320 手机实际浏览器流程。发布时两组界面测试在带 TypeScript 的镜像构建阶段执行，其余十二组在最终运行镜像执行；全部通过才切换站点。图片与视频通过隔离署名投稿、审核、公开读取、文件一致性和视频 Range 请求验收；发布后另检查 HTTPS、版本与实际媒体播放。
