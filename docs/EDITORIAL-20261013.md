# 重点档案、资料卡与最近更新

用户已选择并要求落实本轮优先组合。沿用浅色报刊风格、品牌目录前置、当页阅读与图片适窗预览。

## 本轮范围

1. 整理回力、匹克、Dickies、德芙、罗技降价广告、OPPO母亲节广告、梅见挂签、滴露剧情广告八条已公开记录。新增带附件/来源引用的阅读摘要，明确事件、发布主体、回应与缺口。原文、日期、事实状态保持原样，不将整理完成等同事实核实。
2. 每条已公开事件可生成竖版或横版 PNG 资料卡。包含标题、日期含义、摘要、来源、回应提示、待核提示、完整原图缩略图与本站事件二维码。加载失败时明确提示，可使用文字版；不发出未经用户操作的外部分享。
3. 首页增加最近更新摘要，并提供 `/updates` 独立页。按实际收录、公开更正及摘要整理时间展示，明确不是事件发生时间。撤回/未审核内容不显示；只有来源于公开事件的关联回应才能进入更新流。

## 数据边界

阅读摘要为版本化编辑资料，通过原记录关键字段 SHA-256 绑定。管理员改动正文、日期、主体、回应或核实状态后，旧摘要自动失效，页面回到当前记录的普通概述，避免旧摘要盖过更正。摘要不写入生产数据库，不改写投稿或账号。更新列表只处理允许的公开字段，不暴露审核备注或私有记录。

## 界面与验收

- 详情先图后文；摘要里的附件链接在当前页面打开完整预览。
- 资料卡编辑在事件内展开，保留正常关闭、键盘和移动端行为。预览适配当前窗口，PNG 原尺寸导出；二维码指向 notbuy.top 的事件真实路径。
- `/updates` 延用现有独立阅读页。首页展示最近四条，完整页最多展示100条真实更新。
- 测试覆盖摘要失效、待核状态、公开过滤、更新时间排序、异常引用、长文本、图片失败、二维码及PNG下载。
- 桌面、390px及320px检查，部署前后比对数据库内容、上传文件、访客与受保护配置，保留恢复路径。

本轮不引入新的外部账户、消息订阅服务或统计身份，也不将本地海外研究自动公开。后续关注通知、补证任务与更细流量分析另按本轮使用反馈排序。

## 上线前验收

- `npm run typecheck`、`npm test` 与 `git diff --check` 通过。八条摘要在本地公开 API 正确绑定；原记录的正文、来源、图片和事件日期保持原值。测试库的审核与变更时间为隔离副本，不作为生产数据保持的证明。
- 1280px、390px 与320px浏览器检查通过；附件编号与原附件一致，摘要引用仍在当页打开适窗预览。两种实际下载 PNG 均完成独立二维码解码，目标为对应 notbuy.top 事件。
- 本地测试图片不可用、文字版恢复、长标题及撤回后拒绝生成；测试记录已从隔离副本移除，未写入线上。
- Impeccable 对本轮扩展的完整视觉验收结论为 `ship`，无材料修复项；文档核对保留既有 DESIGN.md 和 sidecar，不添加忽略规则。
- 发布只更新代码。生产数据保持、77条站点地图链接和109个媒体附件的实际验收在发布后执行，以当前版本 `/api/version`、服务器发布清单及本地 `work/editorial-live-acceptance.json` 为准。浏览器调用系统分享不等于已在社交平台发布，本轮未代发外部帖子。
