# 女拳品牌观察 · nvquanpinpai

面向中国大陆市场的品牌消费争议开源收集项目，旨在保障男性消费者的知情权与选择权。记录具体事件及公开表达，保留来源、日期、完整语境、品牌回应、证据层级和纠错入口；收录不表示指控成立，网传标签不能代替证据。海外案例应单列补充，不计为大陆核心案例。

## 功能

- 品牌目录、事件分类、详情先图后文、当页图片预览及缩放。
- 注册投稿使用账户名；免注册投稿必须公开署名，排行标注“未注册”。
- 文字、每条3张图片（每张2 MiB）和1段MP4/WebM视频（25 MiB），支持视频Range请求。
- 管理后台审核、拒绝及撤回，审核后才公开投稿与媒体。
- 贡献者署名和排行，站点整理资料不计入用户排行。
- 服务器永久累计访客，桌面统计侧栏、手机统计后置。

访客按网络地址和浏览器特征作哈希去重，是估算而非精确自然人人数：共享网络可能合并，网络或浏览器变化可能重复。清Cookie和重启不会清零，迁移须保留数据库与访客密钥。未注册署名不验证身份，同名署名可能合并。

## 本地运行

需要Node.js 22.13或更高版本。

```sh
npm ci
npm run build
npm test
npm start
```

访问 http://localhost:8787，后台为 `/admin`。首次运行生成随机管理员凭据，保存在 `data/admin-credentials.json`，仅在服务器本地读取，不提交Git。部分Node版本会输出SQLite实验性提示。

仓库不附带生产数据库、私人投稿、会话、访客记录、第三方截图或视频。代码内品牌名称及品类是公开文字。

## 贡献与纠错

提交原始来源和日期，区分事实、感受、推测及评论，保留上下文、回应和反证。不得提交未经授权的私人信息或群体辱骂。广告、合作人选、待核线索、背景对照及海外补充应分别标注；不能将性别身份本身作为负面标签。补充回应或更正时关联具体记录ID。代码问题可以提交GitHub Issues，不在Issues公开凭据或个人隐私。

未审核媒体仅管理员和注册投稿者可查看；免注册投稿者没有账户投稿列表。注册名不得与已有免注册署名冲突。
